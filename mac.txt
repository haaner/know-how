# Key-Bindings korrigieren

```
mkdir -p $HOME/Library/KeyBindings

echo '{
	/* Remap Home / End keys to be correct */
	"\UF729" = "moveToBeginningOfLine:"; /* Home */
	"\UF72B" = "moveToEndOfLine:"; /* End */
	"$\UF729" = "moveToBeginningOfLineAndModifySelection:"; /* Shift + Home */
	"$\UF72B" = "moveToEndOfLineAndModifySelection:"; /* Shift + End */
	"^\UF729" = "moveToBeginningOfDocument:"; /* Ctrl + Home */
	"^\UF72B" = "moveToEndOfDocument:"; /* Ctrl + End */
	"$^\UF729" = "moveToBeginningOfDocumentAndModifySelection:"; /* Shift + Ctrl + Home */
	"$^\UF72B" = "moveToEndOfDocumentAndModifySelection:"; /* Shift + Ctrl + End */
}' > $HOME/Library/KeyBindings/DefaultKeyBinding.dict
```

Zusätzlich in Terminal.app:

Definiere zwei Mappings im Einstellungen / Profile / Tastatur - Reiter 

	Home	\033OH (Das \033 wird erzeugt ducrh die ESC-Taste)
	End		\033OF


# Hartnäckige Dateien entfernen:

1. command-r boot to recovery
2. csrutil disable in Terminal to disable SIP
3. reboot to command-r recovery again
4. in Terminal cd /Volumes/Macintosh\ HD (or whatever your normal boot drive is named)
5. rm -rf /com.apple.TimeMachine.localsnapshots
6. csrutil enable in Terminal to enable SIP
7. reboot

[ SIP: https://support.apple.com/en-us/HT204899 ]

# Steam

## Lauffähiges Steam auf alten macOS-Versionen

1. Install Steam as normal. Do not the open the app once you drag it to the application folder.
Open Terminal and run this command:

open -a Steam --args -forcesteamupdate -forcepackagedownload -overridepackageurl https://web.archive.org/web/20231212191717if_/media.steampowered.com/client -exitsteam

2. To prevent unintentional updates which may cause the client to be bricked, create a steam.cfg on /Applications/Steam.app/Contents/MacOS with this:

Code:

BootStrapperInhibitAll=enable
BootStrapperForceSelfUpdate=disable
